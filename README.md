Este Proyecto consiste en un formulario de contacto echo con HTML,JS,CSS,PHP y AJAX.
El formulario permite ingresar los datos de contacto y enviarlos mediante una solicitud POST utilizando AJAX.Los datos son recibidos por guardar.php y almacenados en un archivo de texto llamado contactos.txt.
Para poder entrar al proyecto,instalar la carpeta en C:\xampp\htdocs\181843\
Quedaria asi: C:\xampp\htdocs\181843\Asenjo-Tp2-Unidad4
Abrir navegador y copiar este link: http://localhost/181843/Asenjo-Tp2-Unidad4/formulario.html
Una vez llenado y enviado los datos,en la carpeta del proyecto deberia generarse un archivo txt llamado contactos.txt
